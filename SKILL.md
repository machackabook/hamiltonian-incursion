## Run Metadata & Strength Scoring

Every remedy card and every scan carries:

```json
{
  "runs": 0,
  "first_seen": "ISO8601",
  "last_run": "ISO8601",
  "last_success": "ISO8601|null",
  "consecutive_failures": 0,
  "strength": 0.0
}
```

Strength formula (defensive):

```
strength = 1.0 / (1.0 + consecutive_failures) * (1.0 if last_success else 0.3)
```

When `consecutive_failures >= 3` the error is escalated to agent alert + user toast + Jules/Gemini CLI intercept.
